# Verification

The four native targets build and pass their shared policy/resource tests. Core policy runs on Java 21/Gson 2.10.1 and again against each native target’s Gson, including 26.3’s 2.14.0. Tests cover metadata, catalogue isolation, local containment and edit detection, PNG/model/reference budgets, explicit precedence, independent selections, generation retirement and native parsing. Packaging mutation tests inspect installable and source inventories, rejecting preview artwork/rigs, foreign/probe classes, vanilla asset overrides, duplicate entries, wrong dependency/side metadata and Java baselines.

Native resource-manager tests compare all twelve generated artwork slots with packaged PNGs and preserve inherited/explicit ownership. Core controls cover independent selections, disabled styling, partial/overridden/refused artwork, corrupt-map fallback, exact owner-reference volumes, persistent quad/UV boundaries and export. Artifact checks require fourteen exact approved images and eight models in installable/source JARs, refuse retired carriers and old settings screens, require the exact external re:form library, and enforce the legacy Fabric renderer dependency.

The settings tests use the actual staged re:form file owner and existing format 1 representation. They check missing-source initialization, invalid and oversized file preservation, no-op bytes, stale writes and retained missing identities. Controlled application tests distinguish native failure, unreadable source, mismatched generation, cancellation after native entry and closure. A confirmed save survives a failed reload; retry reads that revision without another write. Export retirement before metadata publication leaves an unadmitted partial copy and preserves it when the next copy succeeds. These controlled tests do not establish native widget or loader behavior.

Actual native face baking and mip generation run on all four targets. Both appearances match at texel centers and near-boundaries through mip levels 0–4, including the 68 persistent rim cells. Native-slot geometry has an identical-top control plus separate actual-artwork wall checks; intentional foreign open-top filtering is not forced to match a closed lid. A shifted-grid negative preserves base texels but changes filtered samples. Modern AUTO cutout coverage is tested against its actual alpha cutoff, rather than requiring rescaled mip alpha to remain 255.
