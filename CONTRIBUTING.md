# Contributing

Read [AGENTS.md](AGENTS.md) and the affected development contract. Keep changes focused and preserve native behavior, client-side isolation and independent optional-resource boundaries.

Use the pinned Gradle Wrapper and Java toolchains. Run applicable checks and record actual tested artifacts, inputs and limitations. Resource parsing, model compilation and native visual evidence establish different things. Add a negative case where a boundary can otherwise fail silently.

Do not submit copied donor artwork or rigs without their provenance and applicable permissions. Keep local preview inputs, private task state and personal worlds out of Git. Markdown prose is unwrapped. Use conventional commit subjects and meaningful, proportionate commit descriptions.
