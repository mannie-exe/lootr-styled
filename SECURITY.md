# Security

Report suspected path traversal, resource-budget bypass, unsafe profile parsing or other vulnerabilities privately through GitHub's security reporting for this repository when available. Otherwise contact `mannie@inherent.design` with a minimal reproduction and affected source/artifact identity. Do not include account credentials, private worlds or unrelated personal data.

Profiles are intended as bounded declarative resources, not executable extensions. Resource parsing must not fetch URLs, load arbitrary Java classes or escape an admitted local profile root. This development project has no released version with a supported maintenance window yet.
